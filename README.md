# Fiche de la Tsarine — Snezhnaya Mereona Elianna

Grimoire interactif servant de fiche de personnage RP.

## Utilisation
Ouvrir `index.html` dans un navigateur (double-clic, aucun serveur requis).

## Publier sur GitHub Pages
1. Pousser ce dossier sur un dépôt GitHub.
2. Settings → Pages → choisir la branche (ex: `main`) et le dossier racine `/`.
3. Le site sera disponible à `https://<utilisateur>.github.io/<repo>/`.

## Structure
- `index.html` — le site (pages, styles, scripts)
- `assets/img/tsarine/` — moodboard et portraits de la Tsarine
- `assets/img/snezhnaya/` — images du wiki de la nation, réutilisées pour les décors
- `assets/audio/theme.mp3` — thème musical (Korolevskiy Theatre OST)

## État de la fiche
